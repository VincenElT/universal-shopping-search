# Universal Shopping Search

V1: compare standardized products across marketplaces from one search box.

## V1 scope

- Electronics / computer accessories first
- Search and fuzzy matching
- Compare marketplace listings
- Sort by price
- Affiliate-ready outbound links
- Sample data first; real marketplace integrations come later

## Stack

Next.js + TypeScript + Tailwind CSS

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000.
